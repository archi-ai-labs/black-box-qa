# Contributing to Black-box QA

First off, thank you for considering contributing to Black-box QA! It's people like you that make open-source a great community.

## Development Workflow

1. **Fork the repository** on GitHub.
2. **Clone your fork** locally.
3. Run `npm run setup` to install dependencies and set up the `.env` file.
4. **Create a branch** for your feature or bug fix (`git checkout -b feature/my-new-feature`).
5. **Make your changes**.
6. **Test your changes** by running the development server (`npm run dev`) and verifying everything works as expected.
7. **Commit your changes** (`git commit -am 'Add some feature'`).
8. **Push to the branch** (`git push origin feature/my-new-feature`).
9. **Create a Pull Request** against the main repository.

## AI Agents Friendly
This repository is designed to be easily modified by AI Coding Agents (Antigravity, Cursor, Claude Code). Feel free to use them to generate PRs.

## Code Style
- We use ESLint for linting. Please ensure your code passes `npm run lint` before committing.
- Follow the existing component architecture and naming conventions.

Thanks again for your contribution!
